# Keno Chain: what is translated and what stays a term

Keno Chain is played in Stake's 17 languages (`lang`). Social play is always English (Engine's
rule; `stateUrlDerived.lang()` returns `en` there). The English text is the key; the catalogs are
`src/i18n/locales/<lang>.ts`, merged after the shared UI's, so the game's text wins on a shared key.
`node tools/i18n/check.mjs` lists what a language lacks.

## Stays English (terms)

These are names. They are written the same in every language and are never put through
`translate()`: the code inserts them as values, so a translation only has to leave the
placeholder where it is.

| Term | Where | Why |
|---|---|---|
| Keno Chain | logo, title | the game's name |
| Calm, Bold, Wild (CALM, BOLD, WILD) | risk button, win table tabs, rules | risk names, as Engine lists the modes |
| Unbroken Chain, Golden Chain (UNBROKEN CHAIN, GOLDEN CHAIN) | bonus button and dialog, win table, rules | bonus mode names |
| CALM_3 … WILD_10, CHAIN_10, CHAINMAX_10 | rules, replay | the math file's mode names, which Engine wants shown |
| RTP | rules | the industry's abbreviation (the shared UI keeps it too) |
| Engine, TM and © | disclaimer | the trademark line |
| ×, %, numbers | everywhere | formatted by the language's number format, not by the catalog |

## Translated (game words), one word each

A translation picks one word for each of these and keeps it in every sentence, button and label,
so the rules name exactly what the screen shows.

| English | Meaning |
|---|---|
| hit | a drawn number the player chose |
| miss | a drawn number the player did not choose |
| your number | a number the player chose |
| lucky number | a number the game marks before the draw |
| lucky ball | a lucky number that is drawn |
| lucky round | a round that marks 3 lucky numbers instead of 1 |
| run | hits one after another; the meter's count before lucky balls |
| streak, streak level | the meter: best run + lucky balls; its steps |
| streak multiplier, multiplier | the ×1 to ×25 the streak level gives |
| win table | the table of values by number of hits (PAYTABLE in the menu) |
| risk | what Calm, Bold and Wild are |
| bonus mode, Bonus | what Unbroken Chain and Golden Chain are; the button that opens them |
| draw, drawn | the 10 or 12 numbers the game takes |
| round | one play |
| bet, base bet | real-money play only (social play is English) |
| Random Pick, Clear, Play, Autoplay | the buttons; the rules quote them, so the button and the rules share one key |
| Turbo | the rules' word is the shared UI's TURBO in that language (ターボ, 터보, 极速; TURBO elsewhere) |

## Shared UI words the game overrides

The shared UI's catalog is a slot's: PLAY means "spin" in several languages, and the autoplay
button says AUTO SPIN. Keno Chain's catalogs give these a keno round's words; the keys are listed in
`src/i18n/uiOverrides.ts`. English: AUTO SPINS and AUTO SPIN read AUTOPLAY.

`PLAY`, `PLAYING`, `PLAY AGAIN` (the play bar, written in sentence case by `KenoPlay`),
`AUTO SPINS` (the autoplay sheet's title), `AUTO SPIN` (the autoplay button).

## Rules for a translation

- Keep every `{placeholder}`. `{amount}` may be left out and the word for "bet" written instead.
- Counts (`{hits}`, `{count}`, `{picks}`) can be any number: in languages with plural forms, write
  the sentence so it holds for every number (a label and the number, as "Hits: 3").
- Uppercase keys stay uppercase where the script has case.
- The disclaimer keeps every point Engine's template makes.
- Translations are AI-made; a native check is still open.
